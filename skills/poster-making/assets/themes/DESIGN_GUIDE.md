# 主题设计指南（DESIGN_GUIDE）

新主题动手前先过一遍本清单。原则内化自通用前端设计方法论（frontend-design），
只保留对「静态卡片」场景有效的部分：动效与交互相关内容不适用（卡片是截图，没有交互）。

## 设计立场

每个主题要有一个**签名元素**——它被人记住的那一个细节；签名之外的 everything 保持安静克制。
宁可有主见的收敛，不要无信息量的装饰堆砌。

## 设计流程（四步）

1. **定 token**：在 `themes.yaml` 给齐字段——4~6 个命名色值、至少两个字体角色
   （`font_display` 有性格的标题字体 + `font_body` 互补的正文字体，数据密集主题再加
   `font_utility`）、一个签名元素（`signature` 字段一句话写清）。
2. **过自检清单**（下方）：像镜子前摘掉一件配饰——逐条自查，不过关不写 CSS。
3. **实现**：颜色只从 yaml 字段（或其明度变体）取值；签名元素写在主题 CSS 内；
   字体角色不再在 CSS 里声明（渲染脚本按 yaml 注入）。
4. **截图自省**：渲染 `test_academic.md` → 用看图工具逐页检查（一图值千 token）→
   修 → 再渲染。特别检查：字体是否真的生效、斑马纹/标题色是否与主题同调、
   签名元素在封面上的存在感是否恰到好处（不抢标题）。

## 设计自检清单

- [ ] **默认脸检查**：以下三类是「AI 生成默认脸」，允许用但必须做出差异化签名，
      否则换方向——
      ① 暖奶油底（near #F4F1EA）+ 高对比衬线/陶土点缀；② 近黑底 + 单个酸绿/朱红点缀；
      ③ 报纸风（细规则线、零圆角、密排多栏）。
      （案例：warm-cream 底色本身属于①，靠「手账胶带」签名 + 圆体字体做出辨识度。）
- [ ] **签名唯一**：有且仅有一个签名元素，写进了 `signature` 字段；其余装饰（圆圈、
      点阵、波浪）是基础模板自带的，不算签名，也不要再加同类装饰。
- [ ] **token 完整**：色彩、display/body（必要时 utility）字体角色、签名，三项齐全；
      缺省回退栈是什么清楚（见 themes.yaml 字段说明）。
- [ ] **结构即信息**：装饰符必须编码真实信息——`§`=节、`▸`=要点、页点/页码=页序；
      纯装饰元素要能回答「它帮读者理解了什么」。
- [ ] **色源纪律**：CSS 里每一个 hex/rgba 都能指出来自 yaml 哪个字段（或其明度变体），
      并在 CSS 头部注释里写明对照关系。
- [ ] **字体落地验证**：字体栈里首选的字体在本机真实存在（Playwright 用系统字体渲染，
      栈里字体不存在会静默回退）——渲染样张放大确认字形，不要只看 CSS。
- [ ] **与既有主题并排不撞脸**：新主题渲染样张与现有主题并排对比，封面放一起能一眼区分。
